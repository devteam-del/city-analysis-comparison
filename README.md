# 城市的覆寫：歷史／現況平面比較

三案：東京日本橋、紐約 Cross-Bronx／West Farms、紐約 West Side／Meatpacking。

下載 **[urban-history-comparison.html](urban-history-comparison.html)** 後以瀏覽器開啟，可離線閱讀。

- **描圖對照**：共同重點視窗、相同圖例、前後同號重要改變標記。歷史屋頂／道路判讀與現況官方向量分開標示。
- **航照對照**：完整範圍與重點裁切可切換。日本橋 1974–78／2019；Cross-Bronx 1996／2024；West Side 1951／2024。
- **官方方案**：未落成的日本橋地下化與 Cross-Bronx 願景獨立列出。
- **比較分析**：時間軸、兩國三案比較、後現代視角解讀。

歷史描圖仍有斜線待判讀區，尚未完成全區逐棟測繪。圖上編號是比較位置，不是精確變更邊界。3D 等待平面確認。
