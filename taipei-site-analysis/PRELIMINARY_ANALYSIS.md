# 市民大道一段周邊：初步基地分析與改善建議

2026-09-12｜桌面研究初稿。依使用者最新指示，先運用已取得資訊進行基地分析，不再等待全集閱讀完成。本稿不是現地調查、工程設計或已完成的歷史測繪。

## 判斷與範圍

我建議以「把車站與北側街區接回日常生活」作為改善主題，優先建立地面可穿越、地下可辨識、沿街可停留的公共空間網絡。這是根據現有資料提出的設計判斷，尚不能宣稱沿線每個路口都有相同缺陷。

依原始程式，研究走廊約為環河北路至中山北路、市民大道一段與臺北車站北側周邊；2 公里半徑只作區域背景，不能直接當成基地界線或步行服務範圍。分析必須同時涵蓋道路兩側，不能僅沿用以市民大道為北界的西區門戶計畫範圍。[原始資料](source/README.md)、[設定](source/src/config.py)、[歷史計畫範圍](https://www.gov.taipei/News_Content.aspx?n=F0DDAF49B89E9413&s=4868EF4D13255763&sms=72544237BBE4C5F6)。本稿不代表市民大道全線，也不預設各段均有相同高架、橋下與匝道條件。

## 我會優先做的五件事

### 1. 修補南北穿越，先處理人在路口的連續性

以塔城街、延平北路、重慶北路、太原路及承德路周邊連接點作為踏查候選，逐點畫出實際目的地、合法穿越、地下出入口與無障礙路線。候選名單不是事故排行，也不代表每處都應新增斑馬線。

若證實有過長等待、繞行或轉向衝突，優先檢討行穿線位置、號誌、路口轉角與路側使用；在交通與迴轉軌跡檢核後試辦縮短穿越距離、擴大等候區或庇護空間。不能先填入未量測的車道縮減數量。跨越大道的地面路線應保持可用，地下路線則提供額外選擇。

驗證：實際繞行比、等待時間中位數與高分位數、轉向衝突、輪椅能否連續通過，以及公車、貨運與鄰街車流是否受到轉移影響。

### 2. 把地下街出入口變成街區入口

以「地下街出口—地面人行道—街角—目的地」為最小改善單元。統一地上地下的目的地名稱、出口識別與無障礙導引；整理出入口周邊候車、臨停、自行車及步行空間。不能只增加指標，卻讓使用者上到地面後仍無法過街。

必須另查電梯位置、開放時間與停用時的替代路線；地面公共路徑不宜依賴商場營業時間。先做一個完整節點示範，再決定是否推廣全段。

### 3. 沿真正的步行路線補遮蔭、避雨與免費座位

先量測行走淨寬、日曬、雨天積水、夜間照明與停留位置，再把休息點放在有需求且不阻塞通行的地方。座位應容許短休、等人與攜帶行李者使用，保留不需消費的選擇。

地下街及其他地下設施上方不能逕畫深植大樹；應核對結構、覆土、管線與維護條件，再選擇樹木或其他遮蔭形式。若涉及橋下，須先確認噪音、空污、滴水、照明與維修動線，不能僅因有屋頂就判為適合長時間活動。

驗證：遮蔭路段比例、不同時段停留人數與時間、使用者組成、座位是否排擠通行。Gehl 的提醒在此可轉成「人數與停留時間一起記錄」；不能把人多直接判為舒適，因為排隊和被迫等待也會增加停留。

### 4. 歷史以可核對的軌跡呈現，讓日常用途繼續存在

從北門外、鐵道部、機器局遺構及車站周邊生活史建立多個歷史視窗。取得可靠圖資後，才將已消失建築、工場邊界或軌道位置轉成鋪面標記、沿街展示或導覽。每條線都附年代、來源及定位可信度，未知位置留白。

除官方工程史，也應蒐集工人、商家、通勤者、居民的故事；不同敘述可以並存。Derrida 的閱讀對此提供的是追問檔案如何被選取的工具，不能代替測量，也不等於把任意碎片排列成「解構風格」。

在設計語言上，可讓現代交通設施、日常招牌與歷史遺構被分辨、被閱讀；不必把整條街統一成仿古樣貌。這是本研究的設計立場，不是五位作者共同提出的方案。

### 5. 讓周邊商家與居民參與路側空間分配

若要調整停車、臨停或卸貨，先調查使用時段、物流與無障礙接送需求，再安排替代位置或時段。新增公共空間應保有免費使用部分，不能將全部空間交給需要消費的活動。

記錄店家更替、租金樣本與居民回饋，檢查改善是否伴隨排除。這是需要補證據的風險假設，本輪沒有證明此處已發生迫遷或特定幅度的租金上升。

## 介入尺度與先後順序

| 階段 | 工作 | 決策依據 |
|---|---|---|
| 基線 | 約兩週跨平假日、尖離峰、夜間與雨天調查；建立同範圍平面圖 | 確認真正斷點、施工影響與使用需求；兩週為建議安排，不是已完成調查 |
| 試辦 | 選一處有證據支持的節點，試辦導引、路側配置、候行與休息改善 | 建議追蹤 1–3 個月，與相似未改造節點比較；控制天候、活動與施工差異 |
| 擴大 | 有效措施串成連續步行路徑，再逐段改善 | 同時檢查行人、公車、物流、維護與居民收益 |
| 大型工程評估 | 比較維持結構配合地面改善、局部結構调整、較大規模改造 | 取得流量、替代運輸、地下設施、結構、成本及施工影響資料後再判斷 |

現有資訊不足以推薦整條高架拆除或全面地下化。首要投資建議是可逐點驗證的連接改善；這不預先排除後續大型改造。

## 原始資料方法的修正

- 捷運進出量只能說明站點活動，不能直接均勻分配到周邊街道；需以出口流量、路線觀察補充。
- YouBike 庫存差是淨變動，借還相抵與調度都會影響它，不能稱為實際借還總量。
- 以實際可通行的路網及開放時間計算可達性；2 公里圓只保留為背景範圍。
- 人流也可透過人工計數、定點觀察與經妥善處理的感測資料取得；原 README 所稱只有電信資料能做精細人流的說法過強。
- 本輪未執行猜測 API 取得數字，未生成假熱力圖，未改寫來源程式。
