既有 EVIDENCE_SUPPLEMENT.md 記錄北門資訊圖 B1 連向 Y 區，以及台北車站 B1 圖的相關方向。這些只支持介面存在，不提供可量測的完整線形。承德市民天橋 C076 登記兩段橋梁，亦不能用橋梁端點代替地面樓梯落點。三組介面暫不拼接成完整路徑。

## 建網規則

每個節點記錄 x、y、樓層、z、高程基準、付費區、來源；未知值保持 null。每條邊另記通行方式、方向、開放時間、幾何與驗證狀態。同 XY 不同樓層保持分離，只經核實樓梯、坡道、電扶梯或電梯連接。站體面積與道路示意寬度不作路由幾何。沒有證據的連接標未知，不能將資料缺漏判成實際斷裂。

主比較固定為 A：地面步行網絡；B：同一地面網絡加上已核實的天橋、地下通道與跨層連接。先確認 B 的可行性，再以相同南北起訖點、範圍、半徑與成本定義對比。無障礙與設備停用不另立主要情境，樓梯、電梯、時段作為 B 的附屬條件記錄。未掌握通道時段時，不稱為全天候現況。沒有高程仍能做拓撲，但不填造樓高，不計精確三維距離。等待成本另作時間情境，不混入角度整合度。多層圖網結果與 depthmapX 的 NAIN/NACH 分開命名。

## 計算前缺口

1. Y 區、機捷 A1、臺鐵與北捷的逐段非付費連接及出入口坐標。
2. 電梯中間停靠、閘門兩側位置、管理時段與設備狀態。
3. C076 樓梯／坡道／電梯地面落點，以及各路口合法過街線形。
4. 地下通道與天橋高程、長度；地面路網擴界及邊界敏感度。
5. 實際安裝的計算引擎、版本與三維角度／垂直邊支援測試。

優先完成連接證據，再生成實際比例路網圖。此階段不畫未核实通道，不將分層示意冒充測繪圖。

## A／B 對照交付規則

A、B 並排採相同圖幅及色階，另呈現同一南北 OD 的 B−A 變化。路網未確認前不生成假數值；距離與時間需分開，缺少幾何先只檢查連通關係。A 不含所有天橋與地下通道，是比較基準，不冒稱完整現況。B 的每条新增路徑需有端點、接續路段、公開通行資格與來源；開放時段未知者明列條件，不能用於聲稱某時刻必定可達。
