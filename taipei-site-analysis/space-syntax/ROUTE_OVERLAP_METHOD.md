# 路徑重複率（2026-09-15）

依使用者指示，此階段不加入實測或估計人流權重，只算等權重路徑重複率。

單一路段重複率＝經過該段的不同OD路徑數／共同選定OD總數。例：64組中16組經過，即25%。同一OD重複走同一段只計一次；不同樓層分開，僅平面交叉不算疊合。這是路段被選定路徑使用的比例，不是兩條路線共有長度的比例。

A/B保持相同起訖點、相同分母，每組OD權重1。不可達組數另列，分母不隨A/B可達數縮小。顏色共用尺度：比例低藍、高紅；沒有選定路徑經過維持灰色，並不代表沒有人。

目前既有16樣點共64組OD的頻次已換算為results/route-overlap-rates.json：A最高40/64=62.5%；B最高29/64=45.3125%。既有熱力圖仍標頻次，兩者使用同一分母所以排序與色彩關係一致；百分比資料另列，未宣稱畫面已改版。

公車站、軌道出入口、商業點與善導寺仍在候選清單，尚未替換目前16點；正式替換時重建相同A/B地面OD、擴充至善導寺並重新算分母及路徑，不能沿用本輪64組數值。沒有把候選清單當成已接上路網的節點。

站點人流查核保留作背景，本輪完全不讀取旅運量作權重。模型每組取一條最短路徑，等長替代路徑未分流；結果依OD選點與路徑規則而變。B目前僅增加承德市民天橋，未包含完整地下通道。
