# 新交通與商業節點替換結果

原N1–N8、S1–S8已從活動輸入移除；原始16點只存sources/od-replacement/retired-16-points.json歷史檔。

133個來源選項先合併鄭州A1/A2候車區3筆相鄰同編號站牌，再合併1個相同路網落點，成為129個物理OD。包含17個北捷出口（善導寺6口）、4個機捷出口、39個公車候車區（原42個來源站牌）、50個地下街來源入口、12個台北車站旅客門、7個商業／宗教點、1個轉運站入口選項。分類為合併前數量；同ref不同位置保留後綴，未聲稱全部逐門現勘。

以走廊軸線相對位置分南北，31×98=3,038組OD；A/B各1,738組可計算。其餘1,300組沒有可用來源路徑，分母仍為3,038。18點未找到符合限制的地面接點，另外有小型不連通來源分量；不是現地封閉判定。

所有OD權重1；旅運量、人流估計與商業吸引力均未讀入計算。B只比A多承德市民天橋，地下通道尚未完成。圖面已向東南延伸至善導寺；沿用全段來源網，額外人行道修復範圍同步擴大。

入口連接採來源地面節點或15公尺內不跨主要道路中心的投影；不合限制者保留孤立，不吸附遠處主網。C1、C2、C3、C5、C6、C7及轉運站是命名街面區位代表點，非測量门址，允許35公尺內挑選既有地面線段；原選點與實際路網坐標分別保存。不能把這些點稱為全部核實入口。

路徑計算對地面邊逐點按順序切分，費用保持不變。疊合採同層共線區間累計，同一OD只計一次；浮點共線容差1微米，不是任意空間補接。A/B的路徑幾何總長與重複次數加權路段長相等，驗證誤差0；投影距離不包含高差、等待。
