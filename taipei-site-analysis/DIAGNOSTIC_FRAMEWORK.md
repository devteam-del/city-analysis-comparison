# 市民大道：診斷先於處方

2026-09-15，納入網站 `taipei-site-analysis/index.html`。

## 研究命題

環境條件 → 知覺反應 → 避開行為 → 生活圈分隔。

最關鍵的是知覺是否轉化為行為。「知覺完整性」用來檢驗南北的辨識、連續感與心理壓力；「市民大道切斷南北知覺連續性」保留為研究命題，不寫成已經獲證實的結果。

## L0：先證明結果存在

以兩側活動範圍、土地使用／街道活動、認知地圖、活動日誌及居民訪談核對南北分隔是否存在。差異、距離或道路存在本身，不等於生活圈分隔。也保留連續、部分路段分隔、只在特定人群／時段分隔的結果。

現況：尚無直接居民與活動範圍證據。

## L1：三個機制，各需要三層證據

|機制|環境事實|知覺經驗|行為選擇|
|---|---|---|---|
|A1 物理屏障|日照、噪音實測、街廓與過街寬度、視線|穿越時身體感受與訪談|穿越點人流、沿線活動、到達後是否跨越|
|A2 步行網絡斷裂|walkability audit、步道占用／高差／變窄斷點圖、自行車連續性|改道次數、辨識與順暢感|實際繞路、穿越位置與路線|
|A3 車流時間性|同時段尖峰／離峰車流、號誌運作|穿越壓力與選路理由|尖峰／離峰行人量、方向、地面／地下分流|

優先量測 A3，並同步採集知覺與行為。人流下降只有相關性，需核對天候、工作／上課時程、活動、樣本組成與地下分流，不能直接斷言「人主動避開」。

現況：全段設施幾何、部分西段官方早晚尖峰計數、歷史聲環境與路寬。早晚皆尖峰，不能當成尖峰對離峰。已有資料與缺口見 EVIDENCE_SUPPLEMENT.md。

## L2：B2 是統合診斷機制

檢驗東西向、通過性的車流，如何影響南北向、慢速、在地的生活連結。這組互動串起 A1–A3。

「兩種邏輯互斥」為待驗證命題，需由方向衝突、等待、繞行、知覺與跨側旅程共同支持。六至八段包含平面路段，不將全段概括為高速高架，也不假定生活移動只有南北向。

## L3：B1、B3 待診斷後評估

- B1：如何帶回人流。
- B3：綠帶能否緩解車流壓力。

尚未啟動設計方案；先有 L0 結果與 L1–L2 機制證據，再決定服務對象、空間範圍及介入方法。不以解方語言描述尚未證實的問題。
