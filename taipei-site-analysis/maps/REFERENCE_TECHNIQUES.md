# 參考圖技巧與本圖套用

參考：[Pinterest 圖釘](https://www.pinterest.com/pin/864198616009279529/)（使用者提供短鏈 https://pin.it/PJ1dgk4qw）。2026-09-14 已透過公開圖片目視檢視，頁面題名為 Plan de situation architecture，帳號CITYDIARY。可見圖片735×1040；未據此宣稱原始作者、製作軟體、圖層資料或印刷比例。未將參考圖原檔放進本專案或GitHub。

|參考圖可見技巧|作用|本次套用|
|---|---|---|
|大片淺灰圖底，白色道路|讓街廓和路網形成清楚的明暗關係|底色#E3E5E1，建物#CDD2CB，白色道路雙側線；不恢復白色中心線|
|藍灰色連續河川帶|用一條連續主軸組織整張圖|借用藍灰色作高架主軸#91A4AB／邊色#586E78，仍是高架，不畫成河川|
|綠地採低彩度橄欖色，少數彩色重點|以有限色彩建立次序，不讓所有元素競爭|北側候選圖塊#8D9E82，南側#B5836C；這兩色代表兩側調查選樣，不代表綠地／住宅用途|
|一般背景簡化，少數地標深色強調|區分主要閱讀對象與背景|保留實際建物輪廓，降低一般建物邊線對比，候選圖塊用較深色|
|細字、稀疏標註與小圖例|讓圖面主導閱讀|縮小標題，保留11個短名稱；不畫定位圓點、圖示或引線|
|河面有紋理、道路粗細與點狀圖示|補充環境質感及功能索引|未照搬河紋、圖釘或功能圖示；避免添加未驗證的水域、植栽或用途|

保留使用者的三項較優先要求：**以圖塊替代點位、高架置於地理圖層最上方、道路用雙側線而非中心線。**不照抄參考圖的城市幾何、圖示或文字。

A3／1:5,000比例和地理座標未改。道路側線仍是舊WIDTH資料偏移重建，高架筆畫宽度仍為符號；風格調整沒有提高來源幾何的準確度。完整資料限制見 [README.md](README.md)。
