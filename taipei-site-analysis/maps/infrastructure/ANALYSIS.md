# 市民大道：從三張基礎設施圖建立診斷

2026-09-14／第一輪桌面分析。範圍沿用環河北路—中山北路周邊；三圖同框 1,980 × 1,130 m，A3 原尺寸 1:5,000。**先讀設施分布，再讀相互關係；尚未證明南北生活圈被切斷。**

## 01 公園綠地：先分清「休憩資源」與「植被」

綠色表示 OSM 記錄的公園範圍，淺綠是草地／花園；褐灰表示廣場與鐵道部園區。玉泉公園、圖幅北緣的建成公園等是街區內的休憩資源；行旅廣場則靠近車站與轉乘設施。這些空間不能用同一個「綠地」數字相加：公園包含鋪面和設施，廣場包含植栽，文化園區又有不同開放條件。

玉泉公園的官方防災資料記載面積 **19,265 m²**，並將中興院區列為周邊資源。這支持把「醫院—公園」作為一組日常活動關係來調查；不能直接推定病患、陪病者一定使用公園。資料更新為 2020 年，非本次測量。

**圖上能讀到：**休憩空間與交通廣場具有不同區位和使用情境。**尚不能讀到：**樹冠、實際陰影、可進入的出入口、座椅使用率、有效步行服務範圍。沒有繪出的綠地不代表不存在。

## 02 交通：連接不只發生在地面

高架呈東西向長距離運輸形態；台北車站、轉運站、A1 與北門站則形成多層次轉乘設施。圖面區分地面站體與地下站體投影，地下輪廓不是出口，也不是通道的完整範圍。從平面上看到道路，不能推定所有人都在地面過街。

承德／市民路口 P017 的 **2025-06-25 08:00–09:00** 計數：東側天橋 429、南側平面 230、西側平面 194、北側天橋 135 人次。這說明該時段天橋與平面通行都實際存在；不是整個生活圈的總人數，也不包含所有地下通行。

**圖上能讀到：**需要同時檢查地面、高架下方與地下轉乘的連接。**尚不能讀到：**繞行成本、等候時間、無障礙連續性，以及居民是否避開穿越。交通圖不是完整公車／軌道路網圖。

## 03 商業帶：不同空間形式，可能產生不同停留方式

京站及新光三越站前店所在的混合大樓使用實際建築輪廓著色；並不表示整棟樓、每一樓層都是百貨。後站與華陰／太原採商業處介紹所涉及的街道，標出鄰近現存建物，作為沿街用途調查範圍；**淡褐色不是已確認的商業用途、法定商業區或商圈精確邊界。**

北側已掌握街道型批發與商圈資料，京站則是集中於建築內的商業。兩者可能對街面產生不同影響：前者值得調查店面開口、裝卸、採買與穿行的重疊；後者值得調查建築入口與轉乘動線是否把活動留在室內。這是依空間形式提出的待驗證問題，尚未觀察到實際旅程。

南側補入新光三越站前店，以及依 2017 年官方歷史介紹選取的南陽／許昌／館前／信陽沿街調查圖塊；歷史商圈並不等於 2026 年逐戶現況。地下街尚未完成輪廓核對。因此，**不能用這張圖的著色多寡比較南北商業強弱。**

## 三圖連讀：基地應按「設施交接處」分段調查

1. **玉泉公園—中興院區：日常服務與休憩的交接。**圖中兩者分居高架南北側，適合檢驗是否存在跨側生活連結。先查公園入口、醫院出入口、到達路徑與停留位置；這組關係可作為在地生活的觀測單元，不能被車站旅客流量取代。
2. **北門站—鐵道部—行旅廣場：轉乘與文化／開放空間的交接。**地理鄰近提供連接的可能，但是否形成連續旅程，要核對出口、開放時間、過街方式與實際軌跡。
3. **後站／華陰—京站／轉運站—台北車站：街道商業與大型轉乘的交接。**調查人從哪個層次出站、是否進入商街、停在哪裡，而不是只量車站總進出量。承德路口是已有基準計數可接續的觀測位置。

三組關係顯示：**基地內的活動條件可能隨東西區位與設施類型而變化，不能先把整條市民大道當作同質屏障。**下一步應在這些交接處記錄出入口、同時段的地面／地下行人與停留行為，再檢驗 L0 的跨側活動是否減少，以及 L1 的物理環境、步行網絡、車流時間性是否能解釋差異。此處尚不提出綠帶或導流等處方。
