# 市民大道西段基礎設施診斷：第一輪

2026-09-14｜範圍：環河北路至中山北路的市民大道／鄭州路走廊及與其相接的街道、地下通道。採 L0–L3 架構；本輪完成設施與運作證據盤點、機制分析。沒有現地實測，不宣稱 L0 南北分隔成立，不進入 L3 設計處方。前稿的改善建議保留為研究沿革，暫不作為已被診斷支持的結論。

## 1. 初步判斷

這個基地應視為多層、分時運作的網絡。高架與地面透過匝道交換車流；地下街連接車站與地面出口；地下停車場又將汽車動線帶回地面。重要問題是這些交換位置是否增加在地步行成本，而非僅看高架是否存在。

目前較強的實證是「匝道管制會要求車輛改走另一入口」；尚未取得改道車量、行人延誤或活動範圍縮減的資料。地下街則提供必須納入的連接條件，使「完全分隔」不能成為預設。

## 2. 設施盤點：事實、機制、未知

| 系統 | 已有資料支持的事實 | 機制分析：本研究推論 | 尚缺資料 |
|---|---|---|---|
| 高架主線 | 官方匝道表列出市民高架與鄭州路／環河北路、鄭州路／重慶北路的接點 [S1] | 立體分流可能減少地面穿越車流；橋體與橋墩也可能改變光照、視線及地面配置，效果須分開評估 | 橋面投影、橋墩位置、淨高、主線與地面分時流量；未判定陰影或噪音一定較差 |
| 匝道 | 管制公告明定環河匝道調撥期間，往東車輛改由重慶北路匝道上高架 [S2–S3] | 不同層交通並非完全獨立；運作規則可將入口需求轉到其他地面接點 | 實際選路、轉向量、排隊範圍、衝突及行人延誤 |
| 地面道路與路口 | 原研究範圍包含市民大道一段周邊；官方資料亦以鄭州路命名部分匝道接點 [S1、S5] | 應逐段核對路名與線位，並以完整過街旅程分析；不能用一條中心線代表所有道路 | 道路紅線、各段斷面、人行淨寬、行穿線、庇護空間、號誌時制、轉向車流 |
| 地下街與軌道轉乘 | 台北地下街位於市民大道下方，長 825 公尺，連接相關車站系統與京站／轉運站 [S5] | 地下網絡可能緩解地面阻隔，也可能要求繞路或垂直轉換；需依實際起訖點比較 | 出口與電梯坐標、自由通行邊界、開放時間、路線長度及各層流量 |
| 地下停車 | 官方交通資訊列塔城段停車場位於西寧北路至塔城街地下；2025 年公告另列公中段及塔城段等停車場的經營安排 [S6–S7] | 停車出入口可能構成車行與步行交會；「停車在地下」不等於沒有地面介面 | 進出車道位置、停等與迴轉、是否穿越人行動線、尖峰進出量 |
| 公車、自行車與無障礙 | 現有專案列捷運與 YouBike 資料來源，但未產出經驗證的流量成果 [S8] | 站點存在不等於步行或騎乘路線連續；不同移動能力可能面臨不同成本 | 站牌、停靠與候車空間、自行車道及合法牽行路線、坡道、電梯現況 |
| 地下管線、排水、機電 | 本輪沒有取得可定位的管線或竣工圖 | 不得把未知空間當成無設施空地；但不能因有地下設施便斷定改造不可行 | 管線、地下結構、防水排水、通風及設備出入口圖；此層目前不作性能判定 |

## 3. 一個已核實的時間性機制：環河—重慶匝道

2024-12-17 起的公告設定平日 17–20 時環河匝道調撥，往東車輛改走重慶北路入口。2024-12-19 的後續公告將時段縮短為平日 17–19 時；本輪找到的官方調撥車道表亦列 17–19 時。[S2–S4]

因此，原公告不能單獨代表後續運作。本稿以修訂時段作調查安排依據；調查當日仍應核對有效管制與現場執行，不能把公告當成當天觀察。

目前可建立的因果鏈：

> 匝道入口在特定時段不可使用（公告證據） → 往東上高架車輛被要求改用重慶入口（公告證據） → 地面路段與路口車流可能改變（待計數） → 步行等待、繞行或壓力可能改變（待測量及訪談） → 日常活動聯繫是否縮減（L0 尚未證實）。

調查不能只在一個匝道口數行人。需在環河接點、兩接點之間的地面路段、重慶接點同步记录，並納入地下出口。17 時前後與 19 時前後可作觀察時窗，但尖峰需求本身也在改變，不能把前後差直接當作管制效果。應重複多日，記錄天候、活動、施工、號誌及轉向流量，並找條件相近且不受同一改道影響的對照接點。

## 4. 空間分析單元

### A. 環河北路—西寧北路周邊：快速道路銜接

以環河匝道及相接平面路口為核心，核對進出方向、管制、跨越序列與排隊外溢。此處適合檢查「運作改變如何傳到地面」。尚不能排為最嚴重步行斷點。

### B. 塔城街—延平北路—重慶北路周邊：多種介面交會

依官方資料，這一帶同時涉及地下街、塔城段停車設施及重慶匝道接點。應先畫清相對位置；設施落在同一研究分區，不等於彼此在同一斷面垂直重疊。重慶接點是入口改道機制的直接調查位置；塔城、延平接點可檢查地下與地面步行的轉換。

### C. 重慶北路以東至中山北路：車站與街區連接

以實際出入口、目的地與沿線街口為單元，比較地面、地下及無障礙路線。不能把所有步行都當成南北向，也不能把所有車流都當成東西向穿越交通；方向、起訖與旅行目的需要各自辨認。

以上為調查分區，不是測繪分界或問題強度排名。

## 5. 如何量化基礎設施造成的成本

| 量測項目 | 做法 | 判讀限制 |
|---|---|---|
| 平面繞行 | 同一起訖點，量實際合法路徑與直線距離，記錄比值；地面、地下分列 | 比值大不自動代表道路造成，還可能受站區、地塊與目的地入口限制 |
| 時間 | 分開記錄走路、等號誌、等電梯及上下層時間 | 不預先用一組權重合成分數掩蓋差異 |
| 可通行性 | 對同一起訖點分別檢查一般步行、輪椅及推車路線 | 有樓梯的連接不能直接算為人人可用 |
| 橫斷面 | 分別量總街廓跨距、車行寬度、步行淨寬、候行與避難空間 | 總寬與實際暴露於車流的距離不同；不能只報單一寬度 |
| 光照與視線 | 結構幾何與季節時刻模擬，加現地照度與行人視高視線紀錄 | 高架遮蔭不等於低照度；南北差異也受建築影響 |
| 聲環境 | 同期記錄測點、時段、車流與氣象，區分高架、地面及其他聲源 | 不以單次讀數代表全天，不假定聲音隨距離單調衰減 |
| 需求與選擇 | 地面穿越、地下出入口、沿街活動同步觀察，配合日誌與訪談 | 人少不等於避開；人多也不等於沒有負擔 |

L1 可以先做設施調查，但報告中必須明示 L0 未完成。這次資料不能回答兩側是否形成不同生活圈；還缺土地使用對照、認知地圖、居民活動及跨側聯繫資料。

## 6. 製圖與紀錄狀態

本輪已完成來源盤點、運作時序核對與機制分析文字；尚未取得全區向量圖或生成實測平面圖。北門站資訊圖下載遇逾時，未據其推定出口、電梯數量。舊匝道表已以 2025 年版本更新來源。

應建立同坐標的高架投影、地面路網、地下連接三層平面，並另建管制時段表；不畫成每個設施都在同一位置上下堆疊的假剖面。實際剖面應選在環河接點、重慶接點及一處地下街出口，待取得幾何後製作。
